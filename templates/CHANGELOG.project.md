# 项目变更记录 (Changelog)

> 放在 `<项目>/.fishpond/CHANGELOG.md`（项目交付记录，不是 FishPond 技能自身的 CHANGELOG）。
> 每次交付/发版追加一节；与 git tag / PR 对应。

## 格式
```markdown
## [版本或日期] — YYYY-MM-DD
### 新增
- F-xxx：<功能描述>（卡片 cards/xxx.md）
### 变更
- API：<路径> <改了什么>
- DB：V<序号>__<迁移名> <改了什么>
### 修复
- <问题描述>（根因见 LESSONS.md）
### 文档
- 更新了 ARCHITECTURE / FEATURE_LIST / HANDOFF / NAVIGATION 哪些部分
```
