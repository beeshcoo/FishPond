# 开发日志 (Dev Log)

> 放在 `<项目>/.fishpond/DEVLOG.md`。**每次会话/每张卡片结束时追加一条**（最新在最上）。
> 作用：跨会话记忆 + 让接手的开发人员一眼看懂"做到哪、为什么这么做、下一步"。

## 条目格式（复制这段往上加）
```
### 2026-0x-xx · <卡片/功能ID：简述>
- 做了什么：<改了哪些模块/文件的什么>
- 为什么：<关键决策与取舍，为什么这么改而不是那样>
- 验证：<真实跑的命令 + 结果/退出码；测试是否全绿>
- 影响：<涉及的接口/表/其他模块；是否更新了 ARCHITECTURE/FEATURE_LIST/DATA_MODEL/API_SPEC>
- 遗留/下一步：<未完事项、已知风险、下张卡>
- 提交：<commit hash / PR>
```
