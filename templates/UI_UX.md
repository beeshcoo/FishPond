## 3. 页面规格（每个关键页面一节）
### 页面：订单列表
- 关联功能：F-002 | 关联接口：GET /api/v1/orders
- 布局：左筛选 / 右表格 + 分页
- 关键交互：搜索、筛选状态、点行进详情、批量操作
- **必须覆盖的状态**（缺一即缺陷）：
  ```
  ☐ 正常  ☐ 加载中  ☐ 空数据  ☐ 出错  ☐ 无权限  ☐ 超长内容  ☐ 响应式(窄屏)
  ```

## 4. 交互与反馈规范
```
提交操作：按钮 loading + 成功/失败 toast（不许假成功、不许静默失败）
表单校验：即时校验 + 明确错误文案（人能看懂）
危险操作：二次确认
可访问性：键盘可达 + aria 基本满足
```
